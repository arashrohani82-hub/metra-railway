# BrightTale Kids

**Little stories. Big life lessons.**

BrightTale Kids is an independent AI-assisted short-animation studio for child-friendly social-emotional learning content. The product is intentionally separated from Metra business workflows.

## MVP flow

1. Parent/creator starts a new animation in Telegram.
2. Upload a reference image.
3. Choose a learning topic.
4. BrightTale drafts a short age-appropriate scenario.
5. Creator approves or regenerates the scenario.
6. Production provider generates animation + voice + captions.
7. Creator previews the final MP4.
8. Creator chooses: Publish All / YouTube / Instagram + TikTok / Save only.

## Brand

- Name: BrightTale Kids
- Handle target: `@brighttalekids`
- Tagline: `Little stories. Big life lessons.`
- Primary format: 9:16 vertical short video
- Networks: YouTube Shorts, Instagram Reels, TikTok
- Default language: English
- Content pillars: friendship, emotions, confidence, school, safety, routines, kindness

## Railway

Recommended: create a separate Railway service with Root Directory set to `brighttale`.

Required environment variables are documented in `.env.example`.

## Safety / publishing policy

Publishing always requires a creator approval step. Child-focused content should avoid personal identifying information. YouTube publishing should be marked Made for Kids when applicable; AI-content labels should be supplied to networks when required.
